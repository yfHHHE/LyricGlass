# 原生设置

从菜单栏气泡或歌词右键菜单选择「设置…」，也可在 LyricGlass 激活时按 Command+,。右键与菜单栏只保留四个常用操作：显示/隐藏、锁定位置、设置、退出。

设置窗口分为「外观」「雨滴」「播放与歌词」「关于」。关闭设置不会退出 app；再次打开保留当前分类。

## 外观

长歌词默认换行，保留选定的中英文字体和字号。当前句与下一句分别形成文本块，「两句歌词间距」控制桌面两块之间的距离。桌面窗口保持底边、顶部窗口保持顶边，随内容调整高度；超出最大高度时歌词区域支持滚动，播放按钮保持可见。

顶部收起时是最初的单行小胶囊。悬停或点击后展开，顶部「2 行 / 5 行」切换展开布局：两行采用 A 的居中排版，歌名和横向播放按钮位于标题栏；五行采用 D 的靠左阅读排版，播放按钮移到右侧竖排。默认展开两行。

图钉单独控制「锁定展开」，与行数独立保存。未锁定时移开鼠标自动回到小胶囊，点击展开也不会隐式锁定。锁定后两行或五行都可常驻；再点图钉解锁并收起，收起箭头也会解除锁定并回到胶囊。设置页的行数和锁定与顶部控件保持一致。

五行上下文和当前高亮句使用同一播放时间轴，支持拖动进度与歌词偏移。歌曲首尾会补足可用上下文，歌词不足五行时只显示已有内容。

显示使用 Core Text 原生断行与[实际字形边界](https://developer.apple.com/documentation/coretext/ctlinegetboundswithoptions(_:_:))，去掉未使用字体的行高和上下留白。行距为 0 时仅保留极小的绘制安全余量，包含重音符号、下伸字母和 emoji 的字形仍完整显示。设置预览使用同一套排版，改变窗口宽度、字号或示例语言后重新排版。

桌面框不再为状态和播放按钮常驻预留 92pt 空间，也没有 100/150pt 的固定最小高度。播放按钮在鼠标悬停时以独立小工具条显示；指针移到工具条上仍可操作，离开后隐藏。隐藏歌词、开启鼠标穿透或关闭播放按钮时，一并隐藏工具条。雨滴尺寸随紧凑文本适配。

「顶部灵动岛」可分别调整胶囊宽度 180–1000pt、高度 18–64pt、展开宽度 320–1000pt、展开最大高度 160–720pt，以及距屏幕顶部 0–80pt。默认胶囊 420×24pt，展开后根据内容计算高度。展开形状可选胶囊、圆角长方形、长方形，收起始终为圆润胶囊；调整立即生效并自动保存。原来的胶囊尺寸继续保留，v0.6.3 中曾保存的高卡片尺寸会恢复为 24pt 胶囊，原字体与有效窗口宽度继续保留。有刘海时自动避开摄像头。

强调色以 `#FFF2F6` 为基础：浅粉选中背景、深玫瑰色文字、柔和粉色描边；深色模式使用对应的深玫瑰色调。粉色保留在侧栏选中态、背景与分组层次。按钮、下拉选择器、分段选择、滑块和开关使用 macOS 原生 AppKit 控件与系统反馈，不自行绘制按钮形状；新系统采用系统提供的胶囊与玻璃选择样式，旧系统使用对应原生样式。

采用紧凑的单列分组与选色块。字号直接显示 pt，精确 HEX、加粗、阴影、圆角、留白和字体册入口放在「更多外观选项」中，默认折叠。

- 实时预览共用真实桌面歌词的绘制视图，可切换中英、中文、English 示例
- 三个预设：透明极简、深色毛玻璃、浅色卡片。手动调整后清除预设选中状态
- 中文字体与英文字体分别选择；同一句混排逐段应用，半角数字与标点跟随英文字体
- 字体选择框按当前简短名称自适应宽度，值靠右显示，完整字体名称保留在提示中
- 当前句和下一句独立字号、独立颜色；支持原生选色器和 HEX 输入
- 当前句加粗、文字阴影；两句歌词间距 0–64pt 放在主文字分组中，滑块与数值输入均实时生效
- 显示方式可选桌面与灵动岛、仅桌面、仅灵动岛；可开关下一句与播放按钮
- 桌面歌词宽度 480–1400pt；顶部收起和展开尺寸分别调整，可保持展开，恢复主屏位置同时定位两个窗口
- 透明、纯色、原生毛玻璃；背景色、不透明度、圆角与左右留白
- 毛玻璃跟随系统或固定深/浅外观；设置窗口本身跟随 macOS 明暗模式
- 歌词置顶、鼠标穿透、恢复主屏位置。鼠标穿透仍可从菜单栏解除

外观调整立即应用、自动保存，重启恢复。两种语言的字体独立保存；升级时保留旧字体与其他外观偏好。窗口拖动位置和每首歌的同步偏移沿用原行为，切歌后偏移归零。

### 字体目录

共 23 个选项，按五类整理；其中 11 个家族随应用提供，其余使用系统或本机字体。Source Han/Noto 是同源设计的不同发行，此处明确提供 Noto SC，不重复打包相近的两套发行。

| 分组 | 字体 | 使用方式 |
| --- | --- | --- |
| 中文黑体与楷体 | 思源黑体 / Noto Sans SC | 内置完整桌面可变字体 |
| 中文黑体与楷体 | 苹方 / PingFang SC、冬青黑体 / Hiragino Sans GB | 本机系统字体 |
| 中文黑体与楷体 | 霞鹜文楷 / LXGW WenKai | 内置 Regular / Medium，强调时使用 Medium |
| 中文宋体与明体 | 思源宋体 / Noto Serif SC | 内置完整桌面可变字体 |
| 中文宋体与明体 | 方正兰亭宋 / FZLanTingSong、方正悠宋 / FZYouSong | 使用本机已安装的授权字体 |
| 中文宋体与明体 | 源流明体 / GenRyuMin | 内置 TC 版 Regular / Bold |
| 英文无衬线 | Inter、OpenDyslexic | 内置，中文由系统后备字体补齐 |
| 英文无衬线 | SF Pro、SF Pro Rounded、Helvetica Neue | 系统字体 / 系统设计 API |
| 英文无衬线 | Neue Haas Grotesk | 使用本机已安装的授权字体 |
| 编程等宽 | JetBrains Mono、Fira Code、Cascadia Code | 内置 |
| 编程等宽 | SF Mono、Menlo | 系统字体 / 系统等宽 API |
| 编程等宽 | Berkeley Mono | 使用本机已安装的授权字体 |
| 英文衬线 | New York | 系统衬线设计 API |
| 英文衬线 | Merriweather、EB Garamond | 内置 |

未安装的字体仍显示在对应分组中，但不可选择，不会把系统回退伪装成指定字体。「管理本机字体…」打开字体册，安装后点刷新按钮即可重新检测。已有偏好中的字体若被卸载，会显示缺失提示并以系统字体暂时显示。

字体原始文件未修改。每个内置家族保留完整原始 OFL；`Resources/Fonts/CATALOG.json` 记录固定来源提交、URL、文件大小与 SHA256，原有 OpenDyslexic 记录保留在 `SOURCE.json`。Apple 字体不重新分发。公开调研与许可依据见 [Dynamic-Lyrics 与字体目录调研](dynamic-lyrics-and-fonts.md)。

## 雨滴

在歌词旁显示原模型雨滴，默认关闭。提供「静止」「摇摆」「音频律动」，开关和动作实时生效并自动保存。摇摆只跟随播放与暂停状态；音频律动为需主动连接、授权的实验功能。详见 [雨滴与图标](raindrop-companion.md)。

## 播放与歌词

- 上一首、播放/暂停、下一首，控制当前跟随的播放器；未连接或请求处理中禁用按钮，失败时显示错误
此前分散在右键菜单中的以下功能移入本页：

- 正在播放的歌名、歌手、进度、播放状态与歌词来源
- 自动识别 / Spotify / Apple Music，打开播放器
- 歌词提前、延后、归零
- 重新匹配、导入 LRC、查看来源
- 重试连接、自动化权限、清空歌词缓存
- 使用示例歌词、演示暂停/继续、从头、跳到 18 秒

## 本地验证

```sh
./scripts/check.sh
./scripts/check-appearance.sh
./scripts/build-app.sh
open dist/LyricGlass.app --args --settings
```

原生检查使用独立临时偏好域，不读取播放器或修改正式设置。覆盖：窗口显示后尺寸、五类字体与缺失状态、实际字重、中文覆盖、真实歌词与预览同步、跨进程保存恢复、四项快捷菜单，以及迁入设置页的操作回调。设置控件使用系统原生点击与键盘行为；回归验证原生开关激活、导航操作及设置到真实歌词的联动。原生显示在当前 macOS 桌面会话验证；其他 macOS 和 Intel 硬件实测不由本机回归替代。
