LyricGlass v0.6.2 · 公开测试版

系统要求：macOS 13+，Apple Silicon 或 Intel Mac，Spotify 或系统“音乐”桌面客户端

1. 把 LyricGlass.app 拖进 Applications（应用程序），也可放入自己的 ~/Applications/
2. 打开 app；菜单栏出现气泡图标，默认同时显示主屏底部歌词与顶部灵动岛
3. 在 Spotify 或 Apple Music 桌面端播放歌曲，默认自动识别并跟随
4. 首次使用时，允许读取对应播放器的“自动化”权限
5. 从菜单栏或歌词右键选择“设置…”；快捷菜单保留显示/隐藏、锁定位置、设置、退出

设置：
- 外观：中文、英文字体分别选择；字号、颜色、透明/纯色/毛玻璃背景实时生效并自动保存
- 顶部灵动岛：分别调整收起宽高、展开宽度和最大高度、距顶部位置；形状可选胶囊、圆角长方形或长方形
- 显示方式：桌面歌词与灵动岛同时显示，或仅显示其中一种
- 长歌词：默认换行，保留字号；超过窗口可用高度时在歌词区域上下滚动查看
- 桌面播放按钮：鼠标悬停时在独立小工具条显示，不占常驻歌词高度，移开后隐藏
- 雨滴：显示开关；静止、摇摆和实验性音频律动
- 播放与歌词：上一首、播放/暂停、下一首；自动识别/固定播放器、时间偏移、重新匹配、导入 LRC、清空缓存

实验性音频律动要求 macOS 14.2+。仅主动点击“连接音乐音频”后申请系统音频权限，在本机分析当前播放器的音频强弱；不使用麦克风、不保存或上传音频。暂停或关闭雨滴会停止采集，重启后需重新连接。此功能尚待真实播放器授权实测；“摇摆”为循环动画，不是精确节拍检测。

此版本使用本地 ad-hoc 签名，没有 Apple Developer ID 签名和公证。
如果 macOS 阻止首次打开，请先核实下载来自本项目 GitHub Release。
尝试打开 app 后，进入“系统设置 → 隐私与安全性”，找到 LyricGlass 并选择“仍要打开”。
受组织管理的 Mac 可能不允许此操作。
Apple 官方说明：https://support.apple.com/102445

找不到歌词窗口：再次打开 app 会按所选显示方式恢复主屏位置，也可在“设置 → 外观”恢复主屏位置。
读取不到播放器：检查“系统设置 → 隐私与安全性 → 自动化 → LyricGlass”，允许 Spotify / 音乐，然后在“设置 → 播放与歌词”重试连接。
Music 流媒体缺少曲目信息：暂停后继续一次或切换歌曲，以取得本机播放通知。

应用从 LRCLIB、QQ Music、lrcmux、酷狗、网易匹配同步歌词，每首最多并行两个来源；服务可用性与歌曲覆盖因地区和上游变化。
匹配所需的元数据或歌词 ID 发往 lrclib.net、c.y.qq.com、api.lrcmux.dev、lyrics.kugou.com、music.163.com。
不使用你的登录 Cookie 或账号，不上传播放器 token、音频或本地 LRC 文件。安装包不包含第三方歌词。
成功的同步歌词保存在 ~/Library/Application Support/LyricGlass/Lyrics/，有效期 30 天，最多 200 首，可从设置清空。
播放器模式、外观和雨滴设置自动保存；拖动位置、时间偏移和手工 LRC 关联仅保留本次运行。
