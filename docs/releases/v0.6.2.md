# LyricGlass v0.6.2 · 灵动岛与紧凑歌词

本版合并自 v0.5.2 以来的灵动岛、播放器控制和歌词排版更新，继续以公开测试版提供。

## 更新

- 新增主屏顶部灵动岛，悬停或点击展开歌词、进度和播放控制，可固定展开
- 支持桌面与灵动岛同时显示、仅桌面、仅灵动岛
- 顶部收起宽高、展开宽度与最大高度、距顶部位置分别可调；形状可选胶囊、圆角长方形、长方形，默认收起尺寸 420×24pt
- 上一首、播放/暂停、下一首，只控制当前跟随的 Spotify 或 Apple Music；未连接或请求处理中禁用按钮，失败不自动重试或切换播放器
- 长歌词默认换行并保留字号，窗口随内容调整；超长段落可滚动查看，按钮不覆盖歌词
- 桌面框不再为播放按钮常驻预留空间，改为外侧悬停工具条；去掉未使用字体造成的额外行高，压紧句间距，并保留重音和 emoji 的绘制边缘
- 新设置自动保存，升级保留现有中英文字体、字号、颜色和雨滴偏好；歌词来源、缓存和自动识别沿用现有实现

## 下载与使用

提供 Universal DMG、ZIP 和 SHA256SUMS.txt，支持 Apple Silicon / Intel，要求 macOS 13+。

退出旧版后安装。在「设置 → 外观」调整显示方式、句间距，以及顶部灵动岛尺寸和形状；在「播放与歌词」中使用常驻播放按钮。设置与下载使用无需开发者账号或 API key。

**应用仍为本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证。** 首次打开可能被 macOS 阻止，按包内「首次运行.txt」及 [Apple 官方说明](https://support.apple.com/102445) 操作。

## 验证与边界

- 本机 46 项核心回归，以及原生外观、完整字符换行、像素间距、悬停工具条生命周期、尺寸与形状控件、旧设置迁移检查通过
- Spotify 播放/暂停已有实机验证；上一首/下一首及 Apple Music 控制已核对随播放器发布的命令词典，并完成路由与按钮回调测试，仍需更多实机使用验证
- 刘海、负坐标与小屏幕布局有模拟检查；Universal 包含 Intel 架构，未在全部 Mac 机型和 macOS 版本上实测
- 雨滴音频律动保持实验性：需 macOS 14.2+ 并主动授权，仅本机分析、不使用麦克风、不保存或上传音频，真实播放器音频授权场景仍需验证
