# LyricGlass v0.6.5 · 胶囊播放进度

收起的小胶囊现在也能查看歌曲进度：底部新增白色 1pt 细线，与展开后的进度同步，胶囊高度保持原样。

## 更新

- 收起时显示播放进度，播放、暂停、进度跳转和切歌沿用同一播放时间轴
- 采用清晰的白色 1pt 线条，并与底边描边留出间距；小尺寸胶囊自动调整位置
- 展开仍可选择两行或五行，图钉锁定、自动收起及已有外观设置继续保留

## 下载与使用

提供 Universal DMG、ZIP 和 SHA256SUMS.txt，支持 Apple Silicon 与 Intel，要求 macOS 13+。

退出旧版后安装新包。原有字体、颜色、窗口尺寸、行数与锁定设置继续保留。

本版继续作为公开测试版提供。应用为 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证；首次打开如被系统阻止，请按安装包内「首次运行.txt」操作。
