# LyricGlass v0.1.0 · 公开测试版

为 Spotify 桌面端提供透明双行桌面歌词，当前一句高亮，下一句预览。

## 下载与安装

- 推荐下载 `LyricGlass-v0.1.0-macos-universal.dmg`，打开后把 app 拖到 Applications
- 或下载 ZIP，解压后把 `LyricGlass.app` 拖到 Applications
- 要求 macOS 13+，包含 Apple Silicon（arm64）与 Intel（x86_64）二进制
- 无需 Xcode、命令行工具或 Spotify 开发者账号，需要安装 Spotify 桌面端
- 附 `SHA256SUMS.txt`，可核对下载文件完整性

**首次打开提示：此测试版仅使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。** macOS 可能阻止直接双击打开。在核实下载来源后，按 [Apple 官方说明](https://support.apple.com/102445) 到“系统设置 → 隐私与安全性 → 仍要打开”确认。组织管理的设备可能禁止此操作。

首次运行还需要允许 LyricGlass 读取 Spotify 的自动化权限。

## 已有功能

- 自动读取本机 Spotify 的歌曲和播放进度，跟随切歌、暂停、继续和拖动
- 透明双行、窗口拖动、置顶、鼠标穿透、字号调整
- 歌词提前/延后校准，支持导入当前歌曲的 UTF-8 LRC
- 从 LRCLIB 匹配歌词，网络失败、暂无歌词和纯音乐分别提示
- 支持中文、繁简归一、LRC 多时间标签与间奏空行

## 验证与限制

- 6 组核心回归通过；Apple Silicon 上实测 Spotify 播放及歌词同步
- Universal 二进制包含 Intel 构建，尚未在 Intel 硬件或全部 macOS 版本上实测
- 歌词覆盖与同步准确度依赖 LRCLIB，服务繁忙时可重试或导入 LRC
- 当前只接本机 Spotify 桌面端；网页版和其他 Spotify Connect 设备未验证
- 当前界面为中文；缓存、导入映射及设置只保留在内存，退出后重置
- 仅向 `lrclib.net` 发送歌曲元数据，不上传账号凭据、音频或本地歌词文件

此项目独立于 Spotify；安装包不包含第三方歌词内容。
