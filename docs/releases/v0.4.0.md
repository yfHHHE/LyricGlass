# LyricGlass v0.4.0 · 自动识别播放器

- 默认自动跟随正在播放的 Spotify 或 Apple Music，升级后无需手动切换
- 另一方新开始播放时切换，双方暂停时保留当前歌词及暂停位置
- 双方同时播放且同一轮无法判断先后时保持当前来源；首次启动优先上次跟随的一方
- 菜单显示“自动 · 当前播放器”，也可固定 Spotify / Apple Music，并记住模式
- 单独处理两端权限和超时，拒绝一方不会卡住另一方；超时后恢复不会误判成新开始播放
- 自动模式只探测已运行的客户端，不启动播放器，不更改播放；歌词库、缓存和透明双行窗口沿用现有实现

## 下载和使用

退出旧版后安装 Universal DMG 或 ZIP。要求 macOS 13+，支持 Apple Silicon 和 Intel。

默认“自动识别”，在任一桌面播放器开始播放即可。首次可能需要分别允许读取 Spotify 和“音乐”的自动化权限；可在菜单“播放器”中固定某个来源。权限曾被拒绝时，在系统自动化设置中允许后点击“重试播放器连接”。

Apple Music 部分流媒体场景启动时仍可能需要暂停后继续一次，以接收曲目信息。尚未完成 Apple Developer ID 签名及公证，首次打开按 [Apple 说明](https://support.apple.com/102445) 操作。

## 验证与边界

- 31 项回归，包括自动交接、同时播放、双方暂停、客户端关闭、权限拒绝、超时恢复、手动固定及流媒体元数据缺失
- 本机两个客户端同时暂停时，连续 9 次原生采样保持同一来源与暂停位置；GUI 菜单操作、跨播放器实播交接、Intel 和其他 macOS 版本仍需更多实际使用验证
- 自动模式探测两个已运行播放器的状态，歌词匹配请求仍只发送当前来源的歌曲元数据或歌词来源 ID 到 LRCLIB、网易、QQ、酷狗
- 本机播放通知用于补充 Music 元数据；不读取账号凭据、不上传音频或本地 LRC，安装包不捆绑第三方歌词
