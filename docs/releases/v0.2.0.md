# LyricGlass v0.2.0 · 多源歌词测试版

## 本次更新

- 自动回退：LRCLIB 没有同步歌词或服务不可用时，继续尝试网易、QQ Music
- 同步歌词优先：找到普通歌词后继续查备用源，多源均无时间轴时再显示普通歌词提示
- 更完整的匹配：繁简归一、部分中英文艺名、来源提供的别名、合作歌手；继续校验版本与 ±2 秒曲长
- 本地缓存：成功匹配的同步歌词有效期 30 天，最多 200 首，支持重启后离线使用和菜单清理
- 有限重试：遵守 Retry-After；长时间限流时暂停该来源并切换其他来源
- 缓存损坏或歌曲元数据改变时重新匹配；切歌会取消过时请求
- 菜单显示实际歌词来源与缓存命中状态

## 下载与安装

下载 Universal DMG，打开后把 `LyricGlass.app` 拖入 Applications；也可使用 ZIP。要求 macOS 13+，包含 Apple Silicon 和 Intel 架构。更新前请退出旧版 app。

**此测试版仍仅为 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。** 首次打开可能需要按 [Apple 官方说明](https://support.apple.com/102445)，到“系统设置 → 隐私与安全性 → 仍要打开”确认，再允许读取 Spotify 的自动化权限。

## 数据与边界

- 歌曲元数据或来源 ID 会发送到 LRCLIB、网易、QQ Music，用于匹配歌词
- 不读取浏览器登录 Cookie，不上传 Spotify token、账号、音频或本地 LRC
- 自动缓存位于 `~/Library/Application Support/LyricGlass/Lyrics/`，可从菜单清理
- 网易、QQ 的社区使用端点可能因地区、访问限制或服务调整不可用，程序会继续回退
- 歌词覆盖和时间轴质量因歌曲及录音版本而异；少量未收录的艺名仍可能漏匹配
- 窗口设置和手工 LRC 关联尚不持久化；Intel 构建尚未完成硬件 GUI 实测

回归检查覆盖播放同步、三源回退、匹配、重试、取消与持久缓存。安装包不捆绑第三方歌词内容。
