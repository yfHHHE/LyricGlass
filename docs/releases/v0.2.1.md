# LyricGlass v0.2.1 · 四源歌词测试版

## 本次更新

- 修复《愛情的大壞蛋》漏匹配：补充 Amazing Show / 美秀集团的艺名对照，继续校验歌曲版本与 ±2 秒曲长
- 新增酷狗同步歌词，按 LRCLIB → 网易 → QQ Music → 酷狗回退；普通歌词不会挡住后续同步歌词
- 繁简归一、来源歌手别名及合作歌手匹配，减少跨目录漏匹配
- 成功匹配的同步歌词在本机缓存，有效期 30 天、最多 200 首，支持重启后离线读取及菜单清理
- 服务繁忙时有限退避重试，遵守 Retry-After；长时间限流时切换来源，切歌取消旧请求
- 菜单显示实际歌词来源及缓存状态；诊断支持单独检查四个来源

免费歌词来源的调研和固定样本结果见 [歌词来源与覆盖](https://github.com/yfHHHE/LyricGlass/blob/main/docs/lyrics-sources.md)。

## 下载与安装

下载 Universal DMG，打开后把 `LyricGlass.app` 拖入 Applications；也可使用 ZIP。要求 macOS 13+，包含 Apple Silicon 和 Intel 架构。更新前请退出旧版 app。

**此测试版仍仅为 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。** 首次打开可能需要按 [Apple 官方说明](https://support.apple.com/102445)，到“系统设置 → 隐私与安全性 → 仍要打开”确认，再允许读取 Spotify 的自动化权限。

## 数据与边界

- 匹配所需的歌曲元数据或来源 ID 发往 `lrclib.net`、`music.163.com`、`c.y.qq.com`、`lyrics.kugou.com`
- 不读取浏览器登录 Cookie，不上传 Spotify token、账号、音频或本地 LRC
- 自动缓存位于 `~/Library/Application Support/LyricGlass/Lyrics/`，可从菜单清理；安装包不捆绑第三方歌词
- 网易、QQ、酷狗的社区使用端点可能因地区、访问限制或服务调整不可用，程序会继续回退
- 歌词覆盖和时间轴质量因歌曲及录音版本而异，未识别的艺名仍可能漏匹配
- 窗口设置和手工 LRC 关联尚不持久化；Intel 构建尚未完成硬件 GUI 实测

20 项回归覆盖同步、四源回退、版本及艺名匹配、请求编码、重试、取消与持久缓存。

原生 app 实测《愛情的大壞蛋》通过 QQ 和酷狗分别取得 187 秒版本、38 条时间戳行；《一夜一夜一夜》通过酷狗取得 247 秒版本、53 条时间戳行。时间戳行数不代表歌词质量评分，也不代表整体覆盖率。
