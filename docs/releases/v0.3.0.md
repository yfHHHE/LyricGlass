# LyricGlass v0.3.0 · Apple Music 适配测试版

- 新增系统“音乐”桌面客户端支持：读取曲目、播放状态和实际进度，共用透明双行歌词及现有四源歌词库
- 在菜单的“播放器”中选择 Spotify / Apple Music，并记住选择；两边同时打开时跟随所选一方
- 继续支持暂停、继续、切歌、进度跳转、本地 LRC、时间偏移和歌词缓存
- Apple Music 用秒计算曲长；Spotify 的毫秒单独换算，两个播放器的录音身份互相隔离
- 部分 macOS 无法读取未入库流媒体曲目信息时，使用 Music 的本机播放通知回退；切换过程中丢弃旧歌曲及旧播放器的结果
- 增加播放器诊断与回归，覆盖流媒体通知、权限拒绝、暂停、跳转和停止等状态

## 使用

下载 Universal DMG 或 ZIP，退出旧版后更新 app。要求 macOS 13+，包含 Apple Silicon 和 Intel 架构。

右键歌词或点击菜单栏气泡 → “播放器 → Apple Music”，允许读取“音乐”的自动化权限，然后在系统“音乐”播放歌曲。歌词沿用 LRCLIB → 网易 → QQ Music → 酷狗的来源及本地缓存。

部分 macOS 的未入库流媒体存在 [current track 兼容问题](https://developer.apple.com/forums/thread/798267)。如果启动 LyricGlass 前已播放，且 app 提示缺少曲目信息，请暂停后继续一次或切歌以触发 Music 通知。

## 验证与边界

- 26 项回归，包含 Spotify 兼容、Apple Music 单位、暂停与跳转、通知回退、录音身份、权限及四源歌词链路
- Apple Silicon 上实播 Galaxies / Laura Veirs，读取实时进度，暂停后保持位置，并用实际 Music 元数据匹配 QQ 的 35 行同步歌词
- Intel 和其他 macOS 版本尚未完成硬件 GUI 实测；播放器菜单操作及所有流媒体场景仍需更多实际使用验证
- 仍为 ad-hoc 签名，尚未完成 Apple Developer ID 签名及公证；首次打开参见 [Apple 说明](https://support.apple.com/102445)
- 不读取账号凭据，不上传音频或本地 LRC；歌词匹配请求仍只发送歌曲元数据或来源 ID 到四个既有歌词服务

安装包不捆绑第三方歌词，窗口设置及手工 LRC 关联仍不持久化。
