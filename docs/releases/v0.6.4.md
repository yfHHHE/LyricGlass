# LyricGlass v0.6.4 · 胶囊、两行与五行歌词

顶部收起时保留原来的单行小胶囊，展开后可选两行或五行。图钉单独负责锁定展开，行数和锁定状态都会自动保存。

## 更新

- **小胶囊**：收起时继续预览当前一句，原胶囊尺寸保留；默认 420×24pt，刘海屏自动避让摄像头
- **两行 / 五行**：展开窗口直接切换，设置页也可调整；两行居中显示，播放按钮在标题栏，五行靠左显示，播放按钮在右侧
- **独立锁定**：两种布局都可用图钉锁定；未锁定时移开鼠标自动收起，点击展开不会自动锁定；解除锁定或点击收起箭头回到小胶囊
- **同步上下文**：五行和桌面双行读取同一播放时间轴；切歌、进度跳转、歌词时间偏移同步生效，前奏、间奏及歌曲首尾自动处理
- **完整文字**：长句保留选定字体并自动换行，超过最大高度可滚动，当前句保持可见，播放按钮不覆盖歌词
- **设置与预览**：行数、锁定、尺寸实时生效并保存；保留已有中英字体、字号、颜色、雨滴与显示方式，更新示例歌词片段

## 验证与边界

- 本机 47 项歌词同步、播放状态、来源回退、缓存与匹配回归通过
- 原生胶囊、两行 / 五行、独立图钉、未锁定自动收起、长句换行、滚动、字体、设置持久化与迁移检查通过
- 本机实际安装后验证两行与五行锁定、重启保留五行、解锁恢复原有 29pt 胶囊、鼠标在外侧时未锁定点击展开自动收起
- Spotify 连续进度读取与五行歌词时间轴已核对；Universal 架构、签名、DMG、ZIP 完整性和 SHA256 已验证
- 歌词覆盖取决于上游来源，部分歌曲仍可能没有同步歌词；支持导入本地 LRC
